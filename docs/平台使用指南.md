# EvoQuant 平台使用指南

## 1. 环境准备与 NAS 数据库

系统默认连接绿联 NAS 集中式 PostgreSQL 数据库，也可通过环境变量指定自定义连接串：

```bash
# 代码默认连接串 (绿联 NAS PostgreSQL 主库)
export EVOQUANT_DB_URL='postgresql://postgres:password@192.168.124.18:45869/evoquant'
uv sync --extra dev
```

应用启动时会自动运行幂等建表与模式初始化，也可显式执行 [初始化 SQL](sql/初始化.sql)：

```bash
psql "$EVOQUANT_DB_URL" -f docs/sql/初始化.sql
```

可选的美股 Tiingo 配置：

```bash
export TIINGO_API_KEY='your-key'
export EVOQUANT_US_PROVIDER=tiingo
```

不配置时美股使用 Yahoo Finance，A 股使用 BaoStock。外部行情调用需要网络，并受供应商限流和数据质量影响。

* **NAS Docker 容器在线运行地址**：
  * **绿联 NAS Web 管理台**：`http://192.168.124.18:37749`
  * **NAS PostgreSQL 主库**：`192.168.124.18:45869` (`evoquant`)

* **本地开发方式**：
  分别启动后端和前端：

```bash
uv run evoquant --host 127.0.0.1 --port 8000
cd frontend
npm install
npm run dev
```

访问 `http://127.0.0.1:5173`，健康检查为 `http://127.0.0.1:8000/healthz`。

* **Docker Compose 本地部署方式**：

```bash
export POSTGRES_PASSWORD='replace-with-a-local-password'
docker compose up --build
```

管理台地址为 `http://127.0.0.1:8080`，API 为 `http://127.0.0.1:8000`。PostgreSQL 数据保存在 `postgres_data` 命名卷中。

## 3. 推荐操作顺序

1. 打开 **Paper Trading**，创建一个模拟账户。
2. 打开 **Stock Pool**，同步 US 或 CN 股票池。
3. 打开 **Data Sources**，创建对应市场的 K 线同步任务，等待状态成为 `success` 或 `partial`。
4. 对 `partial` 任务点击重试，仅重新获取失败标的。
5. 打开 **Signals**，选择 US/CN 和策略参数，运行扫描。
6. 检查 buy/hold/sell、评分、目标权重、数据日期、风险标记和原因。
7. 对需要执行的买卖信号创建 Draft。
8. 打开 **Paper Trading** 审核草稿，先 Approve，再 Submit；有疑问则 Cancel。
9. 在 **Risk** 按需切换模式，在 **Audit Log** 核对动作记录。

扫描要求所选市场至少 70% 的可交易标的有缓存行情。首次同步量较大，建议使用分批 K 线任务，而不是同步接口一次拉完五年数据。

## 4. 页面说明

| 页面 | 操作和解读 |
|---|---|
| Overview | 查看策略数量、各状态分布、模拟账户总 NAV、风险模式和审计数 |
| Strategies | 创建策略；保存回测指标；人工修改研究、候选、模拟等状态 |
| Stock Pool | 查看代码、名称、市场、交易所、币种、每手数量和行情覆盖日期 |
| Signals | 运行横截面动量扫描；结果为研究信号；创建订单草稿 |
| Backtests | Sample 回测接受净值/换手序列；Signal 回测使用 PostgreSQL 缓存日线 |
| Evolution | 枚举参数组合并显示候选；需要人工登记，不会自动评估或上线 |
| Paper Trading | 创建/删除账户，查看订单、成交、持仓和草稿生命周期 |
| Data Sources | 同步股票池、创建/重试行情任务、启停 US/CN 收盘后计划 |
| Risk | `research-only` 适合研究；`paper-only` 允许模拟盘；`paused` 阻止模拟提交 |
| Audit Log | 查看系统写入的业务事件及 JSON 负载 |
| User Manual | 管理台内的简版说明；本文件是完整现行指南 |

## 5. 信号参数

默认参数为长周期 120、短周期 20、选取前 20、退出排名 50、单票权重上限 8%、最低成交额 10,000,000、最大波动率 45%、最大回撤 35%。评分公式为：

`0.50 × 长周期收益排名 + 0.25 × 短周期收益排名 - 0.15 × 波动率排名 - 0.10 × 回撤排名`

高收益获得更高收益排名；高波动和更负的最大回撤获得更高风险排名，因此扣分更多。`insufficient_data`、`suspended`、`low_liquidity`、`high_volatility`、`drawdown_limit`、`limit_up`、`limit_down`、`stale_data` 等标记会说明阻断或风险原因。

## 6. 模拟交易规则

- 买入数量为正，卖出数量为负；零数量和非正价格被拒绝。
- A 股按 100 股整数手估算，美股按 1 股估算。
- 草稿只有 `draft` 状态可批准，只有 `approved` 状态可提交；已提交草稿不能取消。涨停阻止买入草稿，跌停阻止卖出草稿，停牌或 stale_data 阻止两个方向。
- `paused` 模式禁止直接订单和草稿提交。真实交易不能开启。
- 成交采用提交时参考价立即整笔成交，不模拟滑点、部分成交或市场深度；草稿提交当前成交费为 0。
- 模拟盘不允许形成净空头；全部卖出会删除持仓，部分卖出保留原平均成本。

## 7. 常见问题

**启动时报数据库连接错误**：确认 PostgreSQL 已运行，数据库已创建，并检查 `EVOQUANT_DB_URL`。默认值是本机 `postgresql://localhost:5432/evoquant`。

**扫描提示覆盖率不足**：先同步股票池和 K 线，在 Data Sources 查看失败项并重试。覆盖率按有行情的 symbol 数除以可交易股票池数计算。

**任务一直 queued/running**：任务在 API 进程内执行，重启会中断；查看后台日志和外部数据源可用性后重新创建任务。

**已批准草稿不能提交**：检查 Risk 是否为 `paused`；恢复后原草稿仍保持 `approved`，可再次提交。

**为什么 Evolution 没有推荐最优策略**：当前页面只生成参数组合，不运行候选回测或自动选择。
