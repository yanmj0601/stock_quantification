# 接口设计文档（API）

本文件对应 `src/evoquant/api.py` 的实际路由，机器可读请求契约见 [openapi.json](openapi.json)。服务启动后的 `/docs`、`/redoc` 提供交互文档。

## 通用约定

默认地址 `http://127.0.0.1:8000`；业务路径前缀 `/api`，健康检查 `/healthz`。请求与响应使用 JSON（DELETE 成功无响应体），字段使用 snake_case。当前没有认证、授权、分页、API 版本前缀或幂等键机制；不能将其视为已实现功能。CORS 允许的 localhost/127.0.0.1 端口为 5173、4173、57818。

日期为 `YYYY-MM-DD`，时间为 ISO 8601 字符串；市场枚举为 `US/CN/CRYPTO`，在线同步和自动调度仅支持 US/CN。ID 是服务生成的字符串，示例 ID 不能直接用于真实请求。数值金额按市场标的计价，账户并未实现跨币种换汇。

状态码：GET/PATCH 默认 200；创建 POST 为 201；删除账户为 204；业务拒绝通常为 400；已实现的资源缺失分支为 404；路径/请求模型验证失败为 422；未处理异常为 500。错误体通常为 `{"detail":"原因"}`；422 的 detail 为包含 loc/msg/type 等信息的数组。并非所有业务异常都已统一映射。

## 业务枚举与策略参数

- StrategyStatus：`research`、`candidate`、`paper`、`small-live-ready`、`production-ready`、`retired`；后两个 ready 状态不是实盘已接通。
- RiskMode：`research-only`、`paper-only`、`paused`。SignalSide：`buy`、`hold`、`sell`。草稿状态：`draft`、`approved`、`cancelled`、`submitted`、`blocked`。
- BarSyncJobCreate.mode：`initial`、`incremental`、`manual`、`retry`；失败任务重试优先使用专用 retry 路由。batch_size 默认 25。
- `cross_sectional_momentum` 后端默认参数：top_n=20、exit_rank=50、lookback_long=120、lookback_short=20、max_weight=0.08、min_amount=0、max_volatility=1、max_drawdown=1。前端信号页主动发送更严格的流动性/波动/回撤参数，不能把页面默认值视为服务默认值。
- 信号扫描 API 使用缓存股票集合并传入空 current_positions；当前扫描不结合选定账户持仓。PaperDraftCreate.trade_session 当前仅为预留输入，服务不持久化或执行 T+1，草稿返回也不含该字段。

## 请求与响应示例

以下为说明结构的示例，不代表当前数据库数据。

```http
POST /api/strategies
Content-Type: application/json

{"name":"动量研究","market":"US","asset_class":"stock","template_id":"cross_sectional_momentum","parameters":{"lookback_long":120,"top_n":20}}
```

```json
{"id":"str_example","name":"动量研究","market":"US","asset_class":"stock","template_id":"cross_sectional_momentum","parameters":{"lookback_long":120,"top_n":20},"status":"research","version":1,"metrics":{}}
```

```http
POST /api/backtests/signal
Content-Type: application/json

{"market":"US","universe":["AAPL","MSFT"],"parameters":{"lookback_long":120,"lookback_short":20,"top_n":20,"exit_rank":50,"max_weight":0.08},"starting_cash":100000}
```

```json
{"metrics":{"total_return":0.01,"cagr":0.08,"volatility":0.1,"sharpe":0.8,"sortino":1.0,"max_drawdown":-0.02,"calmar":4.0,"turnover":0.2},"equity_curve":[100000,101000],"trades":[],"positions":{}}
```

```http
PATCH /api/risk
Content-Type: application/json

{"mode":"paper-only","reason":"开始模拟验证","live_enabled":false}
```

```json
{"mode":"paper-only","live_enabled":false,"updated_at":"2026-09-06T00:00:00+00:00"}
```

无缓存回测响应为 `400 {"detail":"no cached bars for signal backtest"}`。删除账户成功为 204 空响应体。草稿 approve/cancel/submit 不要求业务请求体，前端发送 `{}` 也可。分批同步创建返回201仅表示任务创建，不保证后台成功，应轮询 `/api/data-sync/bar-jobs` 查看进度。

## 契约维护与检查

从仓库根目录执行：

```bash
uv run python tools/export_openapi.py
uv run python tools/export_openapi.py --check
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -p test_api_contract_offline.py
```

生成与检查均不连接数据库或数据源。新增路由、请求字段或枚举后重新生成快照，并同步本文件的语义、响应字段与状态码。前端客户端位于 `frontend/src/api.ts`，其中 GET/POST/PATCH 解析 JSON，DELETE 不解析空响应体。
